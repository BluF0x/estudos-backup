# Overview

Acoplamento determina o quão dependente os módulos são entre si. Uma classe que usa diretamente variáveis privadas de outra classe é fortemente acoplada, já que mudanças na classe que possuí as variáveis impacta diretamente classes que usam essas variáveis. Uma classe que usa uma [[interface]] estável é levemente acoplada, já que apenas uma mudança na interface causará interferência.
