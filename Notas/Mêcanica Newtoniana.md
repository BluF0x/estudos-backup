# Overview
É o estudo de como as coisas se movem, descoberto por Isaac Newton. Não é uma teoria universal, já que não funciona com corpos muito pequenos como átomos e nem com velocidades muito grandes como a velocidade da luz, porém descreve a maioria dos fenômenos físicos de forma simples porém correta. 

# Motivação
Aprender como os objetos se movimentam no espaço.
