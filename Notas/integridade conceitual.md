# Overview
Integridade conceitual refere-se a coerência de um determinado software, ou seja, deve comportar-se de maneira consistente entre todas suas funcionalidades. Esse conceito é relevante tanto para os programadores quanto para o usuário, um sistema deve ter padrões consistentes tanto no código como em sua interface. 
> [[@valenteEngenhariaSoftwareModerna2020#^S5LC6MWH|Marco Tulio de Oliveira Valente, Engenharia de Software Moderna, (2020), p. 88]]

Em termos de gestão, isso significa que um sistema não deve ser desenvolvido a partir de um grande comitê, pois isso tende a funcionalidades demais serem acatadas, gerando *bloat* no sistema.
